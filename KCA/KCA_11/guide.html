Kyverno 정책 실습 – KCA 시험 대비. 본 자료는 Linux Foundation·CNCF와 무관한 독립 교육자료입니다.

개요

항목값
배포 변수LAB_REPO=jangh-lee/cloudnative-cert-labs · LAB_VER=v2026.11.25
목표같은 Pod 파일이 match.any·match.all·Namespace 라벨·exclude selector·exclude subjects에 따라 거부·생성으로 바뀌는 것을 출력으로 확인
범위v1.19 레거시 ClusterPolicy, 단계 0~9 + 과제, 클러스터 kca11
버전kind v0.33.0 · node v1.35.8 · Kyverno v1.19.2(chart 3.9.2) 고정
필요 도구Docker(4GiB 이상), kind, kubectl 1.34+, helm 3.14+ · macOS 또는 Linux
시간준비 약 2분, 실습 약 15분
네트워크가이드는 오프라인 열람, setup은 node 이미지·chart·nginx 이미지 다운로드 필요
격리전용 kubeconfig ~/.kca-lab/, 기존 클러스터·~/.kube/config·현재 context 변경 없음, --as는 실습 클러스터 안의 실습 ServiceAccount만 사용
검증2026-11-25 아래 명령·출력 그대로 실행 확인

적용 전적용 후

YAML 보기 · 11-cpol-any.yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: kca11-require-owner
  labels:
    lecture.kca/lab: kca11
spec:
  background: false
  rules:
    - name: require-owner
      match:
        any:
          - resources:
              kinds:
                - Pod
              namespaces:
                - kca11
              selector:
                matchLabels:
                  tier: web
          - resources:
              kinds:
                - Pod
              namespaces:
                - kca11
              namespaceSelector:
                matchLabels:
                  env: prod
      validate:
        failureAction: Enforce
        message: "owner 라벨 필요"
        pattern:
          metadata:
            labels:
              owner: "?*"
