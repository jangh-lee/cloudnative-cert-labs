Kyverno 정책 실습 – KCA 시험 대비. 본 자료는 Linux Foundation·CNCF와 무관한 독립 교육자료입니다.

개요

항목값
배포 변수LAB_REPO=jangh-lee/cloudnative-cert-labs · LAB_VER=v2026.11.27
목표setup → env → reset → teardown 흐름을 kca01에서 실행하고, 각 스크립트 전후 출력(클러스터 목록·KUBECONFIG·helm 릴리스·실습 리소스)을 확인
범위이후 모든 회차가 같은 스크립트 5개 + lib.sh 사용, 클러스터 이름만 kca<NN>
버전kind v0.33.0 · node v1.35.8 · Kyverno v1.19.2(chart 3.9.2) 고정
필요 도구Docker(4GiB 이상), kind, kubectl v1.35.x(실습용 ~/.kca-lab/bin/kubectl, 1.34~1.36), helm 3.14+ · macOS 또는 Linux
시간준비 약 2분, 실습 약 10분
네트워크가이드는 오프라인 열람, setup은 node 이미지·chart 다운로드 필요
격리전용 kubeconfig ~/.kca-lab/, 기존 클러스터·~/.kube/config·현재 context·helm repo 설정 변경 없음
검증2026-11-25 아래 명령·출력 그대로 실행 확인, 도구 확인 출력은 2026-11-26 실습용 kubectl v1.35.8, setup 출력은 2026-11-25 실행(당시 kubectl v1.37.2)

A2 도구 확인

실습용 kubectl v1.35.8 받기·sha256 확인 성공 시에만 설치 (시스템 kubectl 미변경)
OS=$(uname -s | tr A-Z a-z); ARCH=$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/'); U=https://dl.k8s.io/release/v1.35.8/bin/$OS/$ARCH/kubectl
mkdir -p ~/.kca-lab/bin && (cd ~/.kca-lab/bin && T="$(mktemp kubectl.XXXXXX)" && { curl -fsSLo "$T" "$U" && echo "$(curl -fsSL "$U.sha256")  $T" | shasum -a 256 -c && chmod +x "$T" && mv "$T" kubectl || { rm -f "$T"; false; }; })

kubectl.qYHEYA: OK
